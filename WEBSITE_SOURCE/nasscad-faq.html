What is NASSCAD?

NASSCAD is a 3D CAD application developed by Nasser / NassLab in France. Create mechanical parts with parametric primitives and boolean operations, inspect STEP and IFC models, and export files for fabrication. It runs in a compatible browser or as a Windows x64 desktop application.

Start with the worked 3D printing tutorial or the illustrated user manual.

Should I choose the browser or Windows edition?

Choose the browser edition to start without installation or an account. Choose Windows Setup for an installed desktop application, or Portable to run without an installer. Both Windows editions include MEDUSA and runtime dependencies, and work offline.

Which file formats can NASSCAD import and export?

NASSCAD imports STL, OBJ, 3MF, GLB, PLY, STEP and IFC. Export options include STL (binary or ASCII), OBJ, 3MF, GLB, PLY, STEP and IFC4. SVG and DXF are available for supported section-cut workflows. Editable NASSCAD projects are saved as JSON.

STEP support covers AP203, AP214 and AP242. IFC import covers supported IFC2X3, IFC4 and IFC4X3 geometry. Format support does not guarantee support for every representation or source property. Read the STEP guide and IFC guide before exchanging models.

Are my CAD models processed locally?

CAD model processing runs in your browser or in MEDUSA on your own computer. NASSCAD does not require uploading models to a cloud geometry-processing service. The hosted edition uses Google Analytics for usage statistics; local model processing does not mean the hosted page makes no network requests.

The Windows edition can work offline. Analytics is disabled when the browser application is opened as a local copy. Save your project files explicitly and retain the original imported files.

Is NASSCAD free, and can schools or businesses use it?

Yes. The current browser edition and rebuilt Windows packages use AGPL-3.0-only for NassLab code. Personal, educational, professional and commercial use are allowed without a prior agreement or license fee to NassLab, including paid teaching.

Your original models, drawings and exports remain yours. Using NASSCAD does not by itself place them under the AGPL. Modification and redistribution, including paid distribution, are allowed under the license. Distributors must preserve notices and provide corresponding source; modified network versions must offer their source to their users under section 13.

Read the full license and download the exact corresponding source. Third-party components retain their own licenses. Downloads predating the AGPL release retain their original notices.

Can NASSCAD fully edit or repair imported STEP and IFC models?

Imported STEP and IFC are primarily viewing and inspection workflows. Import does not recreate the source CAD feature history or guarantee complete BIM properties and relationships. Some STEP bodies may remain open shells. NASSCAD does not guarantee repair or lossless import and export.

Keep the original model and inspect exported files in the receiving CAD or BIM application. Check the dimensions, required objects and properties, colours and solid status relevant to your workflow.

Can I make parts for 3D printing?

Yes. Create a dimensioned part, save its editable JSON project, then export STL or 3MF for a slicer. Confirm units, dimensions, orientation and mesh warnings in the slicer before printing.

The mounting-block tutorial provides a concrete example with dimensions and an illustration. NASSCAD is a modelling tool; slicing and printer control take place in your chosen slicer.

Can an AI assistant help me model with NassScript?

An AI assistant can draft JavaScript using the NassScript reference. You review the generated code and run it in NASSCAD to create geometry, apply transformations or animate a scene. You use your own assistant; this workflow does not require a built-in AI service or a NASSCAD account.

Read the NassScript API reference and inspect the four-cylinder engine and Solar System examples. Share only information you intend to send to your chosen assistant.

What hardware and browser do I need?

The browser application requires WebGL 2 and WebAssembly. The desktop downloads are for Windows x64. Available RAM, graphics support, model complexity and mesh resolution determine usable model size and processing time; there is no universal maximum model size.

Try a representative file before planning a large workflow. The Windows MEDUSA engine can accelerate supported operations, but performance depends on your computer and the model. See desktop requirements and the troubleshooting chapters.
