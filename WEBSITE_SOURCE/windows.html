What is included?

NASSCAD 4.7.0, MEDUSA, JavaScript and WebAssembly components, and the runtime DLLs are bundled together. There is no BAT launcher and no separate engine to start. The desktop application manages MEDUSA as a separate native process, starts it automatically and stops its owned process when NASSCAD closes.

The desktop edition communicates with MEDUSA through an internal pipe, without a local HTTP server. The optional standalone MEDUSA download on the homepage is for the browser edition.

Start your first project

  1. Use a Windows x64 computer. Download either Setup or Portable from the links above.
  2. For Setup, run the installer and select the desired destination. For Portable, open the downloaded executable.
  3. Launch NASSCAD. The MEDUSA status indicator should show that its engine is running.
  4. Choose the interactive tutorial, create a primitive, or import a supported model.
  5. Use Save project as to save an editable JSON checkpoint. Use Export for a file intended for a slicer or another application.

Local files and offline use

Modelling and geometry processing run on your computer. The desktop edition works offline and uses native file dialogs to open and save work. You do not need an account. Save project files explicitly: a cached session or recovery offer is not a replacement for a saved project.

Requirements and scope

This download is for Windows x64. Rendering requires a working graphics driver; usable model sizes depend on available RAM and model complexity. Large models need more memory and longer processing times. Imported STEP and IFC models are viewing and inspection workflows, not a guarantee of repair or full preservation during export.

Offline CAD on Windows: common questions

Do I need an account or a cloud workspace?

No account is required to model in NASSCAD. The Windows edition processes models on your computer and works offline. Setup and Portable both include the MEDUSA engine.

Should I choose Setup, Portable or the browser?

Choose Setup for an installed application, or Portable to run without an installer. To try the modelling tools first, launch the browser CAD application. For a first printable part, follow the STL and 3MF modelling tutorial.
