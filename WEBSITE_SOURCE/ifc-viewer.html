Inspect a received IFC model

  1. Preserve the original IFC file and save any work already open in NASSCAD.
  2. Use Import, choose the IFC file and wait for the import to finish.
  3. Frame the model. Select objects through the Objects panel or the viewport.
  4. Inspect supported building geometry and the available object names and colours.
  5. Hide or isolate objects as needed to examine a particular part of the model.
  6. Save a NASSCAD JSON project if you want a checkpoint of the imported scene.

What this viewer is for

NASSCAD provides a practical way to inspect geometry received in an IFC file. It is useful when you need to look at the model locally and examine visible objects. The browser edition processes models on your computer rather than uploading your CAD files for remote geometry processing. The Windows edition can work offline.

Supported content varies with the IFC schema, geometric representations and exporting software. Not every source property, relationship, classification or representation is guaranteed to appear in the imported scene. NASSCAD is not presented as a full BIM authoring or coordination platform.

IFC export is a separate workflow

NASSCAD offers IFC4 export for supported scene geometry. Exporting an imported building model does not guarantee a semantically faithful IFC round trip. Do not assume that original property sets, relationships, identifiers or every source BIM feature survive an import, edit and export.

Keep the original IFC as the authoritative exchange file. Inspect any exported IFC in the receiving BIM application before delivery, and compare the required objects and properties.

Dimensions, placement and performance

Check the imported model's scale and placement before comparing it with other geometry. Rotated object dimensions and world-axis bounding boxes describe different things. Large building scenes can use substantial memory, even when the IFC download itself is comparatively small.

If the scene appears incomplete, inspect the log and try a representative part or smaller file. Save checkpoints before changing performance settings that may require a reload. A viewer image alone does not demonstrate that every IFC property or relationship was imported.

Learn the controls

Use the integrated help and interactive tutorial to learn selection, camera control and panels. Read the IFC and BIM geometry chapter for the documented import, retained information, export and verification workflows.

Opening IFC files: common questions

Can I view an IFC model without creating an account?

Yes. Open supported IFC geometry in NASSCAD's browser edition, with local model processing and no account required. The Windows edition provides an offline application.

Does viewing an IFC file preserve a complete BIM project?

The viewer is intended for geometry inspection. Do not assume that property sets, building relationships or all source information survive import and re-export. Keep the original IFC file for your BIM workflow.

Can I also open mechanical assemblies?

Use the free STEP viewer for AP203, AP214 and AP242 assemblies for supported mechanical models.
