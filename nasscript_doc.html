01Execution model

Whatever you paste into the modal is handed to new Function('return (async()=>{…})()') and run on the main thread. Three consequences account for most surprises.

Scope

Global read, local write

  • Every NASSCAD global is visible
  • Your const/let die with the run
  • To persist: window.x = …
Async

Top-level await works

  • The body is already an async IIFE
  • 26 shipped functions are async
  • A missed await interleaves steps
Thread

No preemption

  • Stop is cooperative, not a kill switch
  • Call scriptCheckStop() per iteration
  • Rendering freezes inside a sync block
scriptLog(...args)
Appends a line to the output pane during the run instead of waiting for the return value. Non-string arguments go through a circular-safe JSON.stringify, so handing it a three.js mesh no longer breaks the display.
scriptCheckStop()
Throws ⏹ Stopped by user if Stop was pressed. Nothing calls it for you — a loop without it cannot be interrupted, because synchronous JS never yields the main thread.
stopScript()
Raises the stop flag. This is what the Stop button calls; from a script it is also how you build a deadline (setTimeout(stopScript, 30000)).
runScript() · showScriptEditor() · hideScriptEditor() · clearScriptEditor()
The modal itself. Opening it requires no password.

Return value, output, history

Whatever the script returns is printed last, prefixed →; with no return you get ✓ OK. A thrown error prints ✗ message in red and is mirrored to the log at ERROR level. The last 20 scripts live in sessionStorage under nasscad_script_hist — they survive a reload, not a tab close.

02Scope & reachability

NASSCAD's globals live in two different places, and the difference is visible from a script. This is verified behaviour, not theory.

// function declarations land on the global OBJECT
typeof window.addPrimitive   // "function"

// top-level const / let land in the global LEXICAL environment only
typeof window.objs           // "undefined"  ← not a bug
typeof objs                  // "object"     ← bare name works
typeof window.NASSCAD_MATERIALS // "undefined"
NASSCAD_MATERIALS.length      // 12

Both kinds are reachable from NassScript, because the script body is evaluated in global scope. The distinction matters in exactly two situations: feature-detecting with typeof window.X (use the bare name instead), and assigning a value you want to survive the run (window.myCache = … works; a bare const does not).

What is not reachable

The 2D sketcher is an IIFE-isolated module: 102 of its functions never touch the global scope. It publishes exactly three names — openSketcher, closeSketcher, and the SK object described in its own section. Likewise every _qf* helper of the fillet module and every _p21* STEP parser helper is a plain global, while the OCCT kernel handle itself is created on demand and only handed out by _occtLoad().

Naming convention

A leading underscore means internal. Those functions work, several are genuinely the best tool for a scripting job, and this page documents the useful ones — but they are not a contract. Anything without an underscore is part of the app's own surface and far less likely to move.

03Data model

A NASSCAD object is a small record wrapping a three.js mesh. Every other API works on this shape.

// one entry of objs[]
{
  id:        42,                  // unique integer — the key used by _csgTree
  name:      'Cylinder_42',        // shown in the object list
  type:      'cylinder',           // source primitive, or 'csg' after a boolean/generator
  mesh:      THREE.Mesh,          // geometry + material + transform
  color:     '#5b8fc9',            // list swatch (independent of an applied material)
  isHole:    false,               // true ⇒ subtracted by the next boolean
  // situational:
  genType:   'gear',                // gear|screw|nut|pipe|lathe|cylind|cubic|tore|arcsphere|circtext|sketch
  genParams: {…},                 // the generator's exact inputs — replayable
  tubeRo, tubeRi,                 // outer / inner radius of a tube
  sphereRes,                      // sphere segment count
  matId:     'inox',                // applied NASSCAD material
  isManifold,                     // false ⇒ CSG will warn
  isOcctResult,                   // came out of a fillet/chamfer
  _poolSlot                       // GeometryPool slot, when pooled
}

The CSG construction tree

_csgTree is a Map keyed by object id. Each node stores the operation, the result centre of gravity, and a full snapshot of every source — enough to rebuild them without the original objects, which is what makes Re-run and Explode non-destructive.

_csgTree.get(id) = {
  op: 'union' | 'subtract' | 'intersect',
  cg: [x, y, z],
  children: [{
    id, name, type, color, isHole, tubeRo, tubeRi, genType, genParams,
    p: [x,y,z], r: [rx,ry,rz], s: [sx,sy,sz],   // position / rotation / scale
    opacity, wireframe,
    _csgTree: {…} | null,                     // nested node — the tree is recursive
    _csgGeo:  {…}                                // serialised geometry, only when not rebuildable
  }]
}

08Boolean CSG

All three booleans go to MEDUSA over local HTTP when it is running — native Manifold C++ on every core. Without it they run in the browser: Manifold WASM (manifold-3d 3.5.4, the same library generation), loaded on the first boolean, one thread. Same protocol, same results, same log lines; the CSG badge and each log line name the engine that did the work.

doCSG('union'|'subtract'|'intersect')
Operates on selObjs, two objects minimum. If the selection mixes solids and holes the operation is forced to solids − holes, whatever you asked for, with solids ordered first. Unions of non-overlapping objects bypass the engine entirely, and a union of union-trees is flattened to its leaves before being sent.

Before looping over booleans

Every doCSG is a local request plus a retessellation. Order matters: union all the holes into one object and subtract once, rather than subtracting N times. It is faster and it leaves a single node in the tree instead of N nested ones.

09Fillet & chamfer — OpenCASCADE

The one place NASSCAD handles real B-Rep locally: the mesh is sewn into a solid, coplanar facets are merged back into faces, and BRepFilletAPI works on that. Entirely in the browser — no MEDUSA involved.

Enters Quick Fillet: edge-chain scanning, mouse picking, radius, then round or chamfer on picked edges or all of them. Interactive only — there is no scriptable equivalent.

Loads and instantiates the kernel — 65 MB, once per session, cached for reinstantiation — and hands back the oc handle, i.e. the full OCCT binding: BRepBuilderAPI_*, BRepFilletAPI_MakeFillet, TopExp_Explorer_2, BRepGProp, ShapeUpgrade_UnifySameDomain_2, BRepCheck_Analyzer…

Volume via BRepGProp, topological validity via BRepCheck_Analyzer, chord length of an edge, and the disposer that calls .delete() on anything you pass it.
_occtResetKernel(why) · _occtIsFatal(msg)
A WASM abort leaves the module unusable. These detect the fatal signatures — out of memory, unreachable, table index out of bounds — and discard the kernel so the next call reinstantiates in about two seconds instead of forcing a reload.
What "B-Rep" means here

The solid handed to OCCT is built from the mesh: one triangle becomes one planar face, then coplanar faces are merged. A cylinder stays N planar strips — it never becomes an analytic cylindrical surface. The fillets and the recovered edges are real; the original surfaces of a part that was never a B-Rep are not recoverable.

Every OCCT instance a script creates must be released by hand with .delete(). Embind has no garbage collector and the WASM heap tops out at 2 GB — this is the cause of "after N fillets nothing works until I reload".

13Export

Scope

Every exporter takes an optional list of objects as its last argument — the same list the Include › Selected shapes option of the Export menu passes. Without it, the export covers the entire scene, as before. The list is matched against objs: objects no longer in the scene are skipped, and bodies are written in scene order. When the list holds a single object, the file name defaults to that object's name.

expSTL(list?) · expSTLascii(list?) · expOBJ(list?) · expPLY(list?) · exp3MF(list?) · expGLB(useDraco, list?)
Mesh exports at setExpQuality resolution. STL (binary and ASCII) and 3MF run a watertightness gate that can prompt. GLB is written in metres, as glTF requires, with one material per colour; 3MF is deflate-compressed with object and per-face colours; PLY is binary with vertex colours. They open the native save picker where the browser supports it, otherwise fall back to a download.
async
expSTEP(list?) · openStepExportModal(list?) · doStepExport() · closeStepExportModal()
Opens the STEP dialog — protocol, fusion mode, custom tolerance, stats — then runs the export with those settings. The picker is deliberately opened during the click gesture, before the B-Rep computation. The file is written as an assembly: one PRODUCT per body, named after it, tied to the root by NEXT_ASSEMBLY_USAGE_OCCURRENCE — a single body stays a single product. Colours travel as a STYLED_ITEM per body plus an OVER_RIDING_STYLED_ITEM per face that differs from it, and opacity below 1 as SURFACE_STYLE_RENDERING_WITH_PROPERTIES.

2 — Real volume and mass

Signed mesh volume including the world transform, converted to mass via the applied material. Verified: a default cube returns exactly 8 000 mm³.

// densities in g/cm³, keyed on NASSCAD material ids
const RHO = {alu:2.70, inox:7.90, acier:7.85, laiton:8.50, cuivre:8.96,
             or:19.30, titane:4.51, 'abs-noir':1.04, 'abs-blanc':1.04,
             caoutchouc:1.20, carbone:1.60, verre:2.50};

function volumeMm3(mesh){
  mesh.updateMatrixWorld(true);
  const g = mesh.geometry, p = g.attributes.position.array;
  const ix = g.index ? g.index.array : null;
  const n = ix ? ix.length / 3 : p.length / 9;
  const m = mesh.matrixWorld;
  const a = new THREE.Vector3(), b = new THREE.Vector3(), c = new THREE.Vector3();
  let v = 0;
  for(let i = 0; i < n; i++){
    const i0 = (ix ? ix[i*3] : i*3) * 3;
    const i1 = (ix ? ix[i*3+1] : i*3+1) * 3;
    const i2 = (ix ? ix[i*3+2] : i*3+2) * 3;
    a.set(p[i0], p[i0+1], p[i0+2]).applyMatrix4(m);
    b.set(p[i1], p[i1+1], p[i1+2]).applyMatrix4(m);
    c.set(p[i2], p[i2+1], p[i2+2]).applyMatrix4(m);
    v += a.dot(b.clone().cross(c)) / 6;   // signed tetrahedron (O,a,b,c)
  }
  return Math.abs(v);
}

let total = 0;
(selObjs.length ? selObjs : objs).forEach(o => {
  const mm3 = volumeMm3(o.mesh);
  const rho = RHO[o.matId] ?? 1.0;
  const g = mm3 / 1000 * rho;           // mm³ → cm³ → g
  total += g;
  scriptLog(`${o.name.padEnd(24)} ${(mm3/1000).toFixed(2).padStart(10)} cm³ `
    + `${g.toFixed(1).padStart(9)} g   ${o.matId || '(no material, ρ=1)'}`);
});
return 'total mass: ' + (total/1000).toFixed(3) + ' kg';

3 — Parametric hole grid

5 — Your own geometry into the scene

A hexagonal prism computed by the script and injected as a first-class object. Verified: 30 × 12 × 34.64 mm for 30 mm across flats.

// extrude a convex polygon [[x,z],…] to height h, base at Y=0
function extrude(poly, h){
  const v = [];
  const tri = (...p) => v.push(...p);
  const n = poly.length;
  for(let i = 0; i < n; i++){                // side walls
    const a = poly[i], b = poly[(i+1) % n];
    tri(a[0],0,a[1], b[0],0,b[1], b[0],h,b[1]);
    tri(a[0],0,a[1], b[0],h,b[1], a[0],h,a[1]);
  }
  for(let i = 1; i < n - 1; i++){            // caps (triangle fan)
    tri(poly[0][0],0,poly[0][1], poly[i+1][0],0,poly[i+1][1], poly[i][0],0,poly[i][1]);
    tri(poly[0][0],h,poly[0][1], poly[i][0],h,poly[i][1], poly[i+1][0],h,poly[i+1][1]);
  }
  const g = new THREE.BufferGeometry();
  g.setAttribute('position', new THREE.Float32BufferAttribute(v, 3));
  g.computeVertexNormals(); g.computeBoundingBox();
  return g;
}

const AF = 30, TH = 12;                       // across flats, thickness
const R = AF / 2 / Math.cos(Math.PI / 6);
const hex = Array.from({length: 6}, (_, i) => {
  const a = i * Math.PI / 3 + Math.PI / 6;
  return [R * Math.cos(a), R * Math.sin(a)];
});

const obj = _finalizeGenToScene({
  label: 'NassScript prism',

  name: n => `hex${AF}_${n}`,
  genType: 'script',

// ---------------------------------------------------------------------------
// VECTOR MATH
// ---------------------------------------------------------------------------

function V(x=0,y=0,z=0) {
  return [x,y,z];
}

function add(a,b) {
  return [
    a[0]+b[0],
    a[1]+b[1],
    a[2]+b[2]
  ];
}

function sub(a,b) {
  return [
    a[0]-b[0],
    a[1]-b[1],
    a[2]-b[2]
  ];
}

function mul(a,s) {
  return [
    a[0]*s,
    a[1]*s,
    a[2]*s
  ];
}

function dot(a,b) {
  return (
    a[0]*b[0] +
    a[1]*b[1] +
    a[2]*b[2]
  );
}

function cross(a,b) {
  return [
    a[1]*b[2]-a[2]*b[1],
    a[2]*b[0]-a[0]*b[2],
    a[0]*b[1]-a[1]*b[0]
  ];
}

function len(a) {
  return Math.sqrt(dot(a,a));
}

function norm(a) {

  const L =
    len(a) || 1;

  return mul(
    a,
    1/L
  );
}

function mod360(x) {

  x %= 360;

  return (
    x < 0
      ? x+360
      : x
  );
}

function jdFromDate(d) {

  return (
    d.getTime() /
    86400000
    +
    2440587.5
  );
}


// ---------------------------------------------------------------------------
// EQUATORIAL POLE → J2000 ECLIPTIC
// ---------------------------------------------------------------------------

function eqPoleToEcl(
  raDeg,
  decDeg
) {

  const ra =
    raDeg * DEG;

  const dc =
    decDeg * DEG;

  const x =
    Math.cos(dc) *
    Math.cos(ra);

  const y =
    Math.cos(dc) *
    Math.sin(ra);

  const z =
    Math.sin(dc);

  return norm([

    x,

    Math.cos(EPS)*y +
    Math.sin(EPS)*z,

    -Math.sin(EPS)*y +
     Math.cos(EPS)*z

  ]);
}


// ---------------------------------------------------------------------------
// ORBITAL ROTATION
// ---------------------------------------------------------------------------

function rotateOrbital(
  v,
  Omega,
  inc,
  omega
) {

  const co =
    Math.cos(Omega);

  const so =
    Math.sin(Omega);

  const ci =
    Math.cos(inc);

  const si =
    Math.sin(inc);

  const cw =
    Math.cos(omega);

  const sw =
    Math.sin(omega);

  const x=v[0];
  const y=v[1];
  const z=v[2];

  return [

    (
      cw*co -
      sw*so*ci
    )*x +

    (
      -sw*co -
      cw*so*ci
    )*y +

    so*si*z,



    (
      cw*so +
      sw*co*ci
    )*x +

    (
      -sw*so +
      cw*co*ci
    )*y -

    co*si*z,



    sw*si*x +
    cw*si*y +
    ci*z
  ];
}


// ---------------------------------------------------------------------------
// KEPLER
// ---------------------------------------------------------------------------

function solveKepler(
  M,
  e
) {

  M =
    (
      (
        M + Math.PI
      ) %
      (
        2*Math.PI
      )
      +
      2*Math.PI
    )
    %
    (
      2*Math.PI
    )
    -
    Math.PI;

  let E =
    e < 0.8
      ? M
      : Math.PI;

  for (
    let i=0;
    i<14;
    i++
  ) {

    const d =
      (
        E -
        e*Math.sin(E) -
        M
      )
      /
      (
        1 -
        e*Math.cos(E)
      );

    E -= d;

    if (
      Math.abs(d) <
      1e-13
    )
      break;
  }

  return E;
}

// ---------------------------------------------------------------------------
// PLANET POSITION FOR A JULIAN DATE
// ---------------------------------------------------------------------------

function planetPos(
  name,
  jd
) {

  const q =
    PE[name];

  const T =
    (
      jd -
      J2000_JD
    )
    /
    CY;

  const a =
    (
      q.a[0] +
      q.a[1]*T
    )
    *
    AU;

  const e =
    q.e[0] +
    q.e[1]*T;

  const I =
    (
      q.I[0] +
      q.I[1]*T
    )
    *
    DEG;

  const L =
    (
      q.L[0] +
      q.L[1]*T
    )
    *
    DEG;

  const p =
    (
      q.p[0] +
      q.p[1]*T
    )
    *
    DEG;

  const N =
    (
      q.N[0] +
      q.N[1]*T
    )
    *
    DEG;

  const w =
    p-N;

  const M =
    L-p;

  const E =
    solveKepler(
      M,
      e
    );

  const rp = [

    a*(
      Math.cos(E)-e
    ),

    a*
    Math.sqrt(
      1-e*e
    )
    *
    Math.sin(E),

    0
  ];

  return rotateOrbital(
    rp,
    N,
    I,
    w
  );
}


// ---------------------------------------------------------------------------
// PLANET POSITION + VELOCITY
//
// Velocity is obtained by centered numerical derivative of the same
// date-dependent JPL model.
// ---------------------------------------------------------------------------

function planetState(
  name,
  date
) {

  const jd =
    jdFromDate(date);

  const h =
    60/DAY;

  const r =
    planetPos(
      name,
      jd
    );

  const a =
    planetPos(
      name,
      jd-h
    );

  const b =
    planetPos(
      name,
      jd+h
    );

  return {

    r,

    v:
      mul(
        sub(b,a),
        1/120
      )
  };
}

// ---------------------------------------------------------------------------
// LAPLACE-PLANE BASIS
// ---------------------------------------------------------------------------

function laplaceBasis(
  ra,
  dec
) {

  const k =
    eqPoleToEcl(
      ra,
      dec
    );

  const ez =
    [0,0,1];

  let ex =
    cross(
      ez,
      k
    );

  if (
    len(ex) <
    1e-8
  ) {

    ex =
      [1,0,0];

  } else {

    ex =
      norm(ex);
  }

  const ey =
    norm(
      cross(
        k,
        ex
      )
    );

  return {
    ex,
    ey,
    ez:k
  };
}


// ---------------------------------------------------------------------------
// SATELLITE RELATIVE POSITION FOR DATE
// ---------------------------------------------------------------------------

function satRelPos(
  name,
  jd
) {

  const s =
    SAT[name];

  const dtDays =
    jd -
    J2000_JD;

  const dtYears =
    dtDays /
    365.25;

  const M =
    mod360(
      s.M +
      360*dtDays/s.P
    )
    *
    DEG;

  // approximate apsidal advance
  const w =
    mod360(
      s.w +
      (
        s.Papsis
          ? 360*dtYears/s.Papsis
          : 0
      )
    )
    *
    DEG;

  // approximate nodal regression
  const N =
    mod360(
      s.N -
      (
        s.Pnode
          ? 360*dtYears/s.Pnode
          : 0
      )
    )
    *
    DEG;

  const i =
    s.i *
    DEG;

  const E =
    solveKepler(
      M,
      s.e
    );

  const a =
    s.a *
    1000;

  const rp = [

    a*(
      Math.cos(E)-s.e
    ),

    a*
    Math.sqrt(
      1-s.e*s.e
    )
    *
    Math.sin(E),

    0
  ];

  const q =
    rotateOrbital(
      rp,
      N,
      i,
      w
    );

  if (
    s.frame ===
    'ecliptic'
  ) {

    return q;
  }

  const B =
    laplaceBasis(
      s.ra,
      s.dec
    );

  return [

    B.ex[0]*q[0] +
    B.ey[0]*q[1] +
    B.ez[0]*q[2],

    B.ex[1]*q[0] +
    B.ey[1]*q[1] +
    B.ez[1]*q[2],

    B.ex[2]*q[0] +
    B.ey[2]*q[1] +
    B.ez[2]*q[2]
  ];
}


// ---------------------------------------------------------------------------
// SATELLITE RELATIVE STATE
// ---------------------------------------------------------------------------

function satRelState(
  name,
  date
) {

  const jd =
    jdFromDate(date);


  // The Moon: Meeus lunar theory, velocity by centred difference ±60 s
  if (
    name === 'Moon'
  ) {

    const dtSec =
      deltaTSeconds(date);

    const hm =
      60/DAY;

    const r0 =
      moonRelPos(jd, dtSec);

    const rA =
      moonRelPos(jd-hm, dtSec);

    const rB =
      moonRelPos(jd+hm, dtSec);

    return {
      r: r0,
      v: mul(sub(rB, rA), 1/120)
    };
  }


  // finite difference ±20 sec
  const h =
    20/DAY;

  const r =
    satRelPos(
      name,
      jd
    );

  const a =
    satRelPos(
      name,
      jd-h
    );

  const b =
    satRelPos(
      name,
      jd+h
    );

  return {

    r,

    v:
      mul(
        sub(b,a),
        1/40
      )
  };
}

// ΔT = TT − UT in seconds (Espenak & Meeus polynomials).
// The lunar theory runs on Terrestrial Time; the calendar gives UT.
function deltaTSeconds(
  date
) {

  const y =
    date.getUTCFullYear() +
    (date.getUTCMonth() + 0.5) / 12;

  // measured ΔT has stayed at 69.1–69.4 s since 2017 (IERS); the 2005–2050
  // Espenak–Meeus parabola overshoots it by several seconds today
  if (y >= 2017 && y < 2050) return 69.2;

  if (y >= 2005 && y < 2017) {
    const t = y - 2000;
    return 62.92 + 0.32217*t + 0.005589*t*t;
  }

  if (y >= 1986 && y < 2005) {
    const t = y - 2000;
    return 63.86 + 0.3345*t - 0.060374*t*t + 0.0017275*t**3
         + 0.000651814*t**4 + 0.00002373599*t**5;
  }

  if (y >= 1961 && y < 1986) {
    const t = y - 1975;
    return 45.45 + 1.067*t - t*t/260 - t**3/718;
  }

  if (y >= 1941 && y < 1961) {
    const t = y - 1950;
    return 29.07 + 0.407*t - t*t/233 + t**3/2547;
  }

  // outside 1941–2050: long-term parabola (good to about a minute)
  const u = (y - 1820) / 100;
  return -20 + 32*u*u;
}


// Geocentric ecliptic longitude, latitude (rad) and distance (km) of the
// Moon, mean equinox of date. `jde` is a Julian Ephemeris Day (TT).
function moonEclipticOfDate(
  jde
) {

  const T = (jde - J2000_JD) / CY;

  const poly = (c) =>
    c[0] + T*(c[1] + T*(c[2] + T*(c[3] + T*c[4])));

  const Lp = poly([218.3164477, 481267.88123421, -0.0015786,  1/538841,   -1/65194000]) * DEG;
  const D  = poly([297.8501921, 445267.1114034,  -0.0018819,  1/545868,   -1/113065000]) * DEG;
  const M  = poly([357.5291092, 35999.0502909,   -0.0001536,  1/24490000, 0]) * DEG;
  const Mp = poly([134.9633964, 477198.8675055,   0.0087414,  1/69699,    -1/14712000]) * DEG;
  const F  = poly([93.2720950,  483202.0175233,  -0.0036539, -1/3526000,   1/863310000]) * DEG;

  const A1 = (119.75 + 131.849    * T) * DEG;
  const A2 = ( 53.09 + 479264.290 * T) * DEG;
  const A3 = (313.45 + 481266.484 * T) * DEG;

  // decreasing eccentricity of the Earth's orbit
  const E  = 1 - 0.002516*T - 0.0000074*T*T;
  const Ek = [1, E, E*E];

  let sl = 3958*Math.sin(A1) + 1962*Math.sin(Lp - F) + 318*Math.sin(A2);
  let sr = 0;
  let sb = -2235*Math.sin(Lp) + 382*Math.sin(A3) + 175*Math.sin(A1 - F)
         +   175*Math.sin(A1 + F) + 127*Math.sin(Lp - Mp) - 115*Math.sin(Lp + Mp);

  for (const [d, m, mp, f, cl, cr] of MOON_TA) {
    const arg = d*D + m*M + mp*Mp + f*F;
    const k = Ek[Math.abs(m)];
    sl += cl * k * Math.sin(arg);
    sr += cr * k * Math.cos(arg);
  }

  for (const [d, m, mp, f, cb] of MOON_TB) {
    sb += cb * Ek[Math.abs(m)] * Math.sin(d*D + m*M + mp*Mp + f*F);
  }

  return {
    lon: Lp + sl * 1e-6 * DEG,
    lat: sb * 1e-6 * DEG,
    distKm: 385000.56 + sr * 1e-3
  };
}


// Precession of ecliptic coordinates from the equinox of `jde` back to
// J2000.0 — Meeus, formula 21.5, run from epoch `jde` to J2000.
function eclipticOfDateToJ2000(
  lon,
  lat,
  jde
) {

  const AS = DEG / 3600;               // arcseconds → radians
  const T  = (jde - J2000_JD) / CY;    // starting epoch
  const t  = -T;                       // interval to J2000

  const eta =
    ((47.0029 - 0.06603*T + 0.000598*T*T) * t
    + (-0.03302 + 0.000598*T) * t*t
    + 0.000060 * t*t*t) * AS;

  const Pi =
    174.876384 * DEG
    + (3289.4789*T + 0.60622*T*T) * AS
    - (869.8089 + 0.50491*T) * t * AS
    + 0.03536 * t*t * AS;

  const p =
    ((5029.0966 + 2.22226*T - 0.000042*T*T) * t
    + (1.11113 - 0.000042*T) * t*t
    - 0.000006 * t*t*t) * AS;

  const A = Math.cos(eta)*Math.cos(lat)*Math.sin(Pi - lon) - Math.sin(eta)*Math.sin(lat);
  const B = Math.cos(lat)*Math.cos(Pi - lon);
  const C = Math.cos(eta)*Math.sin(lat) + Math.sin(eta)*Math.cos(lat)*Math.sin(Pi - lon);

  return {
    lon: p + Pi - Math.atan2(A, B),
    lat: Math.asin(Math.max(-1, Math.min(1, C)))
  };
}


// Geocentric position of the Moon in metres, J2000 ecliptic frame.
// `jdUT` is the calendar Julian Day (UT); ΔT is added here.
function moonRelPos(
  jdUT,
  dtSec
) {

  const jde = jdUT + dtSec / DAY;

  const m = moonEclipticOfDate(jde);
  const q = eclipticOfDateToJ2000(m.lon, m.lat, jde);

  const r = m.distKm * 1000;

  return [
    r * Math.cos(q.lat) * Math.cos(q.lon),
    r * Math.cos(q.lat) * Math.sin(q.lon),
    r * Math.sin(q.lat)
  ];
}

  //
  // Example Earth:
  //
  // Earth ←──── barycentre ────→ Moon

  // -----------------------------------------------------------------------

  function attach(

      V();

        x.b.mass;

            x.b.mass

        add(
          cv,
          mul(
            x.s.v,
            x.b.mass

      mul(
        cr,
        1/total
      );

      mul(
        cv,
        1/total
      );

      sub(
        baseState.r,
        cr
      );

      sub(
        baseState.v,
        cv

      const x of rel

      'Rhea',
      'Titan',
      'Iapetus'

  // TRUE BARYCENTRIC FRAME OF OUR SIMULATED SUBSET

    V();

    V();

    const b of bodies

// ===========================================================================
// J2 — PLANET OBLATENESS
//
// Important for close satellites:
// Phobos, Io, Mimas, Enceladus, etc.
//
// Still classical Newtonian gravity — but planet is not treated as a
// mathematically perfect sphere.
// ===========================================================================

function addJ2Acceleration(
  moon,
  parent
) {

  if (
    !CFG.useJ2 ||
    !parent.j2 ||
    !parent.eqRadiusKm
  )
    return;


  const r =
    sub(
      moon.r,
      parent.r
    );

  const r2 =
    dot(
      r,
      r
    );

  const rr =
    Math.sqrt(
      r2
    );

  if (
    rr < 1
  )
    return;


  // pole direction is constant: computed once per planet, then cached
  const k =
    parent._pole ||
    (parent._pole = eqPoleToEcl(parent.poleRA, parent.poleDec));


  const z =
    dot(
      r,
      k
    );


  const q =
    z*z/r2;


  const mu =
    G *
    parent.mass;


  const R =
    parent.eqRadiusKm *
    1000;


  const coeff =
    1.5 *
    parent.j2 *
    mu *
    R*R
    /
    (
      r2*r2*rr
    );


  const f =
    5*q -
    1;


  // in place: no allocation in the physics hot path
  const back =
    moon.mass /
    parent.mass;

  for (
    let c=0;
    c<3;
    c++
  ) {

    const aj =
      coeff *
      (
        r[c]*f -
        2*z*k[c]
      );

    moon.a[c] +=
      aj;

    // approximate equal/opposite reaction
    parent.a[c] -=
      aj*back;
  }
}


// ===========================================================================
// NEWTON N-BODY GRAVITY
// ===========================================================================

function computeAccelerations() {

  for (
    const b of bodies
  ) {

    b.a[0]=0;
    b.a[1]=0;
    b.a[2]=0;
  }


  // exact pairwise Newtonian interactions
  for (
    let i=0;
    i<bodies.length;
    i++
  ) {

    const a =
      bodies[i];


    for (
      let j=i+1;
      j<bodies.length;
      j++
    ) {

      const b =
        bodies[j];


      const d0 =
        b.r[0]-a.r[0];

      const d1 =
        b.r[1]-a.r[1];

      const d2 =
        b.r[2]-a.r[2];


      const r2 =
        d0*d0 +
        d1*d1 +
        d2*d2;


      if (
        r2 < 1
      )
        continue;


      const invr3 =
        1 /
        (
          r2 *
          Math.sqrt(r2)
        );


      const fa =
        G *
        b.mass *
        invr3;


      const fb =
        G *
        a.mass *
        invr3;


      a.a[0] +=
        fa*d0;

      a.a[1] +=
        fa*d1;

      a.a[2] +=
        fa*d2;


      b.a[0] -=
        fb*d0;

      b.a[1] -=
        fb*d1;

      b.a[2] -=
        fb*d2;
    }
  }


  // oblateness of parent planets
  for (
    const b of bodies
  ) {

    if (
      b.kind ===
      'moon'
    ) {

      addJ2Acceleration(
        b,
        byName.get(
          b.parent
        )
      );
    }
  }


  // -----------------------------------------------------------------------
  // OPTIONAL SOLAR 1PN
  // -----------------------------------------------------------------------

  if (
    CFG.useGR
  ) {

    const sun =
      byName.get(
        'Sun'
      );

    const C =
      299792458;


    for (
      const b of bodies
    ) {

      if (
        b.kind !==
        'planet'
      )
        continue;


      const r =
        sub(
          b.r,
          sun.r
        );

      const v =
        sub(
          b.v,
          sun.v
        );


      const R =
        len(r);


      const mu =
        G *
        (
          sun.mass +
          b.mass
        );


      const rv =
        dot(
          r,
          v
        );

      const v2 =
        dot(
          v,
          v
        );


      const c =
        mu /
        (
          C*C*
          R*R*R
        );


      const A =
        4*mu/R -
        v2;


      const ag = [

        c*
        (
          A*r[0] +
          4*rv*v[0]
        ),

        c*
        (
          A*r[1] +
          4*rv*v[1]
        ),

        c*
        (
          A*r[2] +
          4*rv*v[2]
        )
      ];


      for (
        let c=0;
        c<3;
        c++
      ) {

        b.a[c] +=
          ag[c];

        sun.a[c] -=
          ag[c] *
          b.mass /
          sun.mass;
      }
    }
  }
}


// ===========================================================================
// VELOCITY VERLET
// ===========================================================================

function physicsStep(
  dt
) {

  // previous accelerations, copied into per-body buffers (no allocation)
  for (
    const b of bodies
  ) {

    const a0 =
      b.a0 ||
      (b.a0 = [0,0,0]);

    a0[0] = b.a[0];
    a0[1] = b.a[1];
    a0[2] = b.a[2];
  }


  const h =
    0.5 *
    dt *
    dt;


  // positions

  for (
    let i=0;
    i<bodies.length;
    i++
  ) {

    const b =
      bodies[i];

    const a =
      b.a0;


    b.r[0] +=
      b.v[0]*dt +
      a[0]*h;

    b.r[1] +=
      b.v[1]*dt +
      a[1]*h;

    b.r[2] +=
      b.v[2]*dt +
      a[2]*h;
  }


  // new acceleration

  computeAccelerations();


  // velocities

  for (
    let i=0;
    i<bodies.length;
    i++
  ) {

    const b =
      bodies[i];

    const a0 =
      b.a0;

    const a1 =
      b.a;


    b.v[0] +=
      0.5 *
      (
        a0[0]+a1[0]
      )
      *
      dt;


    b.v[1] +=
      0.5 *
      (
        a0[1]+a1[1]
      )
      *
      dt;


    b.v[2] +=
      0.5 *
      (
        a0[2]+a1[2]
      )
      *
      dt;
  }
}


// ===========================================================================
// ENERGY DIAGNOSTIC
// ===========================================================================

function totalNewtonianEnergy() {

  let E=0;


  for (
    const b of bodies
  ) {

    E +=
      0.5 *
      b.mass *
      dot(
        b.v,
        b.v
      );
  }


  for (
    let i=0;
    i<bodies.length;
    i++
  ) {

    for (
      let j=i+1;
      j<bodies.length;
      j++
    ) {

      E -=

        G *

        bodies[i].mass *

        bodies[j].mass

        /

        len(
          sub(
            bodies[j].r,
            bodies[i].r
          )
        );
    }
  }


  return E;
}


// ===========================================================================
// VISUAL MAPPING
//
// PHYSICS remains in SI metres.
// Only the rendering is compressed.
//
// Planets use global asinh compression.
// Moons use a second local scale around their real parent.
// ===========================================================================

function displayGlobal(
  r
) {

  const R =
    len(r);


  if (
    !R
  )
    return new THREE.Vector3();


  const d =

    CFG.planetScale *

    Math.asinh(
      (
        R/AU
      )
      /
      CFG.planetCompressionAU
    );


  const f =
    d/R;


  // physical J2000 ecliptic:
  // x,y,z
  //
  // NASSCAD:
  // X horizontal
  // Y vertical
  // Z depth

  return new THREE.Vector3(

    r[0]*f,

    r[2]*f,

    r[1]*f
  );
}


function displayMoon(
  b
) {

  const p =
    byName.get(
      b.parent
    );


  const parentPos =
    p.mesh
      ? p.mesh.position
      : displayGlobal(
          p.r
        );


  const r =
    sub(
      b.r,
      p.r
    );


  const R =
    len(r);


  if (
    !R
  )
    return parentPos.clone();


  const km =
    R /
    1000;


  const d =

    CFG.moonLocalBase +

    CFG.moonLocalScale *

    Math.asinh(
      km /
      CFG.moonCompressionKm
    );


  const f =
    d/R;


  return (

    parentPos
      .clone()
      .add(

        new THREE.Vector3(

          r[0]*f,

          r[2]*f,

          r[1]*f
        )
      )
  );
}

let seed =
  0x4e415353;


function rnd() {

  seed |= 0;

  seed =
    seed +
    0x6D2B79F5
    |
    0;

  let t =
    seed;

  t =
    Math.imul(
      t^t>>>15,
      t|1
    );

  t ^=
    t +
    Math.imul(
      t^t>>>7,
      t|61
    );

  return (

    (
      t^t>>>14
    )
    >>>
    0

  )
  /
  4294967296;
}

function makeOfficialObject(

) {

  const seg =

    b.kind==='sun'

      ? 64

      : (
          b.kind==='planet'
            ? 40
            : 24
        );


  // Use NASSCAD's normal PS-sized sphere basis.
  // Visual size lives in mesh.scale.
  const geo =

    new THREE.SphereGeometry(

      PS/2,

      seg,

      Math.max(
        12,
        Math.round(
          seg*0.65
        )
      )
    );


  const mat =

    new THREE.MeshPhongMaterial({

      color:b.color,

      shininess:
        b.kind==='sun'
          ? 2
          : 8,

      emissive:
        b.kind==='sun'
          ? 0xff7600
          : 0x000000,

      emissiveIntensity:
        b.kind==='sun'
          ? 1
          : 0
    });


  const mesh =
    new THREE.Mesh(
      geo,
      mat
    );


  const s =
    displayRadius(b)
    /
    (
      PS/2
    );


  mesh.scale.setScalar(
    s
  );


  mesh.castShadow=true;
  mesh.receiveShadow=false;


  scene.add(
    mesh
  );


  // ---------------------------------------------------------
  // Official NASSCAD object
  // ---------------------------------------------------------

  objCnt++;


  const o = {

    id:objCnt,

    name:b.name,

    // Real NASSCAD type → normal selection / properties / persistence
    type:'sphere',

    mesh,

    color:b.color,

    isHole:false,

    sphereRes:seg,


    // Extra metadata.
    // NASSCAD permits enriched object records.
    astro:{

      engine:
        'NASS_SOLAR_REAL',

      kind:
        b.kind,

      parent:
        b.parent || null,

      massKg:
        b.mass,

      radiusKm:
        b.radiusKm,

      physicalPositionM:
        b.r,

      physicalVelocityMS:
        b.v
    }
  };


  objs.push(
    o
  );


  b.mesh =
    mesh;

  b.nassObj =
    o;


  // ---------------------------------------------------------
  // SATURN RINGS
  // ---------------------------------------------------------

  if (
    b.rings
  ) {

    const rg =
      new THREE.RingGeometry(

        (PS/2)*1.35,

        (PS/2)*2.30,

        128
      );


    const rm =
      new THREE.MeshBasicMaterial({

        color:0xc8b88d,

        side:
          THREE.DoubleSide,

        transparent:true,

        opacity:0.62
      });


    const ring =
      new THREE.Mesh(
        rg,
        rm
      );


    ring.rotation.x =
      Math.PI/2;


    mesh.add(
      ring
    );
  }


  // ---------------------------------------------------------
  // TRAIL
  // ---------------------------------------------------------

  if (
    CFG.trails &&
    b.kind !== 'sun'
  ) {

    const tg =
      new THREE.BufferGeometry();


    const tm =
      new THREE.LineBasicMaterial({

        color:b.color,

        transparent:true,

        opacity:
          b.kind==='moon'
            ? 0.30
            : 0.20
      });


    const tl =
      new THREE.Line(
        tg,
        tm
      );


    scene.add(
      tl
    );


    b.trailGeo=
      tg;

    b.trailMat=
      tm;

    b.trailLine=
      tl;

    b.lastTrailSim=
      -Infinity;
  }
}

function sampleTrails() {

  if (
    !CFG.trails
  )
    return;


  for (
    const b of bodies
  ) {

    if (
      !b.trailGeo
    )
      continue;


    const step =

      (
        b.kind==='moon'

          ? CFG.trailSampleMoonDays

          : CFG.trailSamplePlanetDays
      )

      *

      DAY;


    if (
      Math.abs(
        state.simSeconds -
        b.lastTrailSim
      )
      <
      step
    )
      continue;


    b.lastTrailSim =
      state.simSeconds;


    const p =

      b.kind==='moon'

        ? displayMoon(b)

        : displayGlobal(
            b.r
          );


    b.trail.push(
      p.clone()
    );


    const cap =

      b.kind==='moon'

        ? CFG.trailPointsMoon

        : CFG.trailPointsPlanet;


    if (
      b.trail.length >
      cap
    )
      b.trail.shift();


    b.trailGeo.setFromPoints(
      b.trail
    );
  }
}

          x => {

            }
          }

        (
          Array.isArray(
            b.mesh.material
          )

            ? b.mesh.material

            : [b.mesh.material]

        ).forEach(

          m =>
            m.dispose &&
            m.dispose()
        );
      }
    }

      objs.filter(
        o =>

function speedIndex() {

  let best = 0;

  for (let i = 1; i < SPEEDS.length; i++) {
    if (Math.abs(SPEEDS[i] - state.daysPerSecond) <
        Math.abs(SPEEDS[best] - state.daysPerSecond))
      best = i;
  }

  return best;
}

function speedLabel(dps) {

  const a = Math.abs(dps);

  const txt =
    a >= 1    ? a + ' day/s'

    :            Math.round(a*1440) + ' min/s';

  return (dps < 0 ? '− ' : '') + txt;
}

function frame(
  now
) {

  if (
    !state.alive
  )
    return;


  let realDt =

    Math.min(

      0.10,

      (
        now -
        state.lastReal
      )
      /
      1000
    );


  state.lastReal =
    now;


  if (
    !state.paused
  ) {

    state.accumulator +=

      realDt *

      state.daysPerSecond *

      DAY;


    let steps=0;

    const tBudget =
      performance.now();


    while (

      Math.abs(
        state.accumulator
      )
      >=
      CFG.dtSeconds

      &&

      steps <
      CFG.maxStepsPerFrame

      &&

      performance.now() - tBudget <
      CFG.frameBudgetMs

    ) {

      const dir =

        Math.sign(
          state.accumulator
        )
        ||
        1;


      physicsStep(

        dir *
        CFG.dtSeconds
      );


      state.simSeconds +=

        dir *
        CFG.dtSeconds;


      state.accumulator -=

        dir *
        CFG.dtSeconds;


      steps++;
    }


    // Behind schedule (slow machine or very high speed): drop the backlog,
    // otherwise the clock keeps racing long after speed() was lowered.
    if (
      Math.abs(state.accumulator) >=
      CFG.dtSeconds
    ) {

      state.accumulator = 0;
    }


    if (
      realDt > 0
    ) {

      const inst =
        steps *
        CFG.dtSeconds /
        DAY /
        realDt;

      state.achievedDaysPerSecond =
        state.achievedDaysPerSecond == null
          ? inst
          : state.achievedDaysPerSecond*0.9 + inst*0.1;
    }


    updateVisuals();

    sampleTrails();
  }


  // -----------------------------------------------------------------------
  // DIAGNOSTIC EVERY 2 s
  // -----------------------------------------------------------------------

  if (
    now -
    state.lastDiag
    >
    2000
  ) {

    state.lastDiag =
      now;


    if (
      !CFG.useGR
    ) {

      const E =
        totalNewtonianEnergy();


      state.energyDrift =

        (
          E -
          state.initialEnergy
        )

        /

        Math.abs(
          state.initialEnergy
        );
    }


    if (
      hud
    ) {

      const d =
        currentDate();

            'T',
            '  '
          )

            'Z'
          )

        '\n'

        +

        (
          state.paused
            ? 'PAUSED'
            : 'RUN'
        )

        +

        '  × ' +

        state.daysPerSecond
          .toFixed(2)

        +

        ' day/s'

        +

        (
          !state.paused &&
          state.achievedDaysPerSecond != null &&
          state.achievedDaysPerSecond <
            0.95*Math.abs(state.daysPerSecond)

            ? ' (this machine: ' +
              state.achievedDaysPerSecond.toFixed(2) +
              ')'

            : ''
        )

        +

        '  ·  '

        +

        bodies.length

        +

        ' gravitating Objects'

        +
